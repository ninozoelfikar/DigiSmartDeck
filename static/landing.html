Kemampuan Inti

Dibangun untuk Keandalan Jam Kerja Panjang

Bukan sekadar pengetikan web biasa, DigiSmartDeck menyimulasikan perangkat keras langsung pada kernel sistem operasi host.

Dikte Suara Berkelanjutan

Bebas dari timeout pemutus 3 detik dan bebas dari chime notifikasi Android saat jeda hening. Anda memiliki waktu penuh untuk menyusun instruksi yang rumit.

Kernel-Level Input (uinput)

Simulasi perangkat keras murni. Dapat digunakan di layar display manager (GDM, LightDM), layar terkunci (Lock Screen), sesi Wayland, dan lingkungan X11.

Latensi Ultra-Rendah

Didukung kabel USB via ADB reverse port forwarding dengan respon di bawah 1 milidetik, serta jaringan Wi-Fi LAN lokal dengan latensi di bawah 15 milidetik.

Proteksi Akses Fisik PIN

Hanya ponsel yang memasukkan 6-digit kode PIN yang muncul di layar terminal PC host yang dapat terhubung. Terlindungi dari akses perangkat liar di jaringan yang sama.

Aplikasi Ringan (~5.6 MB)

APK mandiri sangat hemat ruang penyimpanan tanpa bundel model AI berat di ponsel. Mendukung layar penuh tanpa gangguan popup navigasi peramban.

Umpan Balik Akustik & Haptik

Sintesis audio Web Audio menghasilkan kepuasan klik switch mekanikal fisik (housing thock dan transient ping) dengan getaran haptik presisi pada setiap sentuhan.

Karakter teks yang diketikkan atau didiktekan dialirkan secara instan ke kernel OS host tanpa pernah disimpan ke file disk, database, atau catatan log server.

Klarifikasi & Detail Teknis

Apakah saya wajib menginstal aplikasi di ponsel?

Tidak wajib. Anda dapat langsung membuka alamat IP server di Google Chrome atau peramban lainnya di ponsel. Namun menginstal file APK resmi (~5.6 MB) memberikan pengalaman layar penuh imersif tanpa gangguan bilah navigasi peramban.

Apakah aman untuk mengetikkan kata sandi atau data sensitif?

Sangat aman. DigiSmartDeck beroperasi secara murni lokal (on-premise). Paket input dieksekusi langsung ke subsistem kernel sistem operasi host tanpa disimpan ke penyimpanan disk atau server internet pihak ketiga.

Bagaimana jika jaringan Wi-Fi di tempat saya kurang stabil?

Sambungkan ponsel ke PC menggunakan kabel data USB biasa. Sistem secara otomatis mendeteksi sambungan melalui port reverse forwarding dengan latensi instan di bawah 1 milidetik tanpa memerlukan koneksi Wi-Fi.

Bagaimana cara mengaktifkan lisensi setelah pembelian?

Setelah proses pembayaran selesai, Anda akan menerima 20 karakter kunci lisensi berstandar resmi (DLIFE-XXXXX-XXXXX-XXXXX atau DMONT-XXXXX-XXXXX-XXXXX). Masukkan kunci tersebut bersama alamat email Anda di menu lisensi aplikasi pada ponsel Anda.
