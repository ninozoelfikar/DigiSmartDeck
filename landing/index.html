Klarifikasi & Pertanyaan Populer

Apakah saya wajib menginstal aplikasi di ponsel?

Tidak. Anda dapat langsung membuka alamat IP server di Google Chrome, Safari, atau Firefox di ponsel tanpa instalasi apa pun. Namun, kami menyarankan menginstal APK DigiSmartDeck resmi (~5.5 MB) untuk menikmati mode Fullscreen Imersif murni bebas dari segala popup peringatan browser.

Apakah aman untuk mengetikkan password atau data sensitif?

Sangat aman. DigiSmartDeck menganut prinsip Zero-Telemetry dan Air-Gapped Ready. Seluruh komunikasi berlangsung 100% lokal antara HP dan PC melalui port 8080 dengan proteksi PIN pairing 6-digit. Teks ketukan langsung dikirim ke kernel OS dan tidak pernah direkam ke disk atau internet.

Bagaimana jika jaringan Wi-Fi di tempat saya tidak stabil?

Anda dapat menyambungkan HP ke PC menggunakan kabel data USB biasa. Sistem kami mendukung ADB Reverse Port Forwarding otomatis yang memberikan respons input latensi instan di bawah 1 milidetik tanpa bergantung pada sinyal Wi-Fi.

Bagaimana cara mengaktifkan lisensi Pro setelah pembelian?

Setelah pembayaran selesai, Anda akan menerima 16-karakter Kunci Lisensi (misal DSDP-ABCD-1234-EFGH). Buka Menu di aplikasi DigiSmartDeck di ponsel Anda, pilih menu License, masukkan kunci lisensi dan email Anda, dan semua fitur Pro otomatis terbuka seketika.
